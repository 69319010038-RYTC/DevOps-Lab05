# Jigsaw Drive

เกมจิ๊กซอว์ที่สร้างด้วย HTML, CSS และ JavaScript แบบไม่ใช้ไลบรารีเพิ่มเติม เลือกได้ 2 ระดับ:

- **ง่าย:** 20 ชิ้น (5 × 4)
- **ยาก:** 40 ชิ้น (8 × 5)

## วิธีเล่น

1. เปิด `index.html` ในเว็บเบราว์เซอร์
2. เลือกระดับความยาก แล้วลากแต่ละชิ้นไปวางในช่องที่ตรงกับภาพต้นฉบับจาง ๆ บนกระดาน ชิ้นส่วนจะเข้าที่และล็อกเมื่อวางในช่องที่ถูกต้อง
3. กด **เริ่มใหม่** เพื่อสุ่มชิ้นส่วนและเริ่มจับเวลาใหม่
4. กด **เปิดเพลง** เพื่อเริ่มเสียงพื้นหลัง เพลงจะเล่นวนซ้ำ และมีเสียงเอฟเฟกต์เมื่อวางชิ้นส่วนถูกช่อง

เกมใช้ภาพ `car.jpeg` และไฟล์เสียง `background-music.mp3`, `jigsaw-drop.mp3` ซึ่งต้องอยู่ในโฟลเดอร์เดียวกับ `index.html` ให้เปิดผ่านเว็บเซิร์ฟเวอร์แบบ static เช่น Live Server ใน VS Code เพื่อให้เล่นเพลงพื้นหลังได้ เบราว์เซอร์จะเริ่มเล่นเพลงหลังจากกดปุ่ม **เปิดเพลง** ตามข้อจำกัดการเล่นเสียงอัตโนมัติ
